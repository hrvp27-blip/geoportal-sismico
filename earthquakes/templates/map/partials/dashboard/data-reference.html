Especificaciones de entrada

Formatos de archivo aceptados por el visor. Los archivos marcados como requeridos deben estar presentes para que la plataforma funcione correctamente.

Catálogo Sísmico

CSV/UTF-8 Requerido

Archivo de texto delimitado por comas. La primera fila debe ser una cabecera con los nombres de campo exactos indicados en la tabla. La codificación debe ser UTF-8.

Campo Tipo Estado Descripción
date string Requerido Fecha y hora del evento (AAAA-MM-DD HH:MM:SS)
lat / latitude float Requerido Latitud decimal WGS84, rango −90° a 90°
lon / longitude float Requerido Longitud decimal WGS84, rango −180° a 180°
mw / magnitude float Requerido Magnitud momento Mw
depth float Requerido Profundidad focal en kilómetros
smajax* float Requerido Semieje mayor de la elipse de error de localización (km)
sminax* float Requerido Semieje menor de la elipse de error de localización (km)
strike* float Requerido Azimut del semieje mayor de la elipse de error (grados)
eventid string Requerido Identificador único del evento
is_main_shock boolean Requerido Indica si es el choque principal: true/false (por defecto true si se omite)

*Nota: Si no dispone de los campos smajax, sminax o strike, indique 0 en esos campos para que el visor utilice los valores por defecto.

Zonas Fuente Sísmica

ZIP/Shapefile Requerido

Archivo ZIP que contiene un Shapefile con los polígonos de las zonas fuente. Se admiten geometrías de tipo Polygon y MultiPolygon. Se recomienda proyección WGS84 (EPSG:4326).

Componente Estado Descripción
.shp Requerido Geometría vectorial de los polígonos de zona fuente
.shx Requerido Índice de posición de geometría
.dbf Requerido Tabla de atributos alfanuméricos (nombre, código de zona…)
.prj Requerido Definición de la proyección cartográfica

Matriz de Completitud

CSV/UTF-8 Requerido

Define los años de completitud en que el catálogo se considera completo para cada umbral de magnitud. El visor filtra automáticamente los eventos que no cumplen el criterio de completitud correspondiente a su año. Si no se proporciona, Mc se determina automáticamente por MAXC.

Año de completitud Mc
1900 5.0
1960 3.5
2000 2.0
